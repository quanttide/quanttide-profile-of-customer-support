# 课题申请发到哪个邮箱

## 适用场景

准备提交课题申请的实训参与者，不清楚投递渠道；或拿到了课堂任务但不知道后续申请材料发往何处。

## 解答

两个邮箱职能不同：

| 邮箱 | 用途 | 费用 |
|---|---|---|
| **hr 邮箱** | 提交课题申请 | — |
| **class@quanttide.com** | 获取课堂任务（如 GitHub 协作入门任务） | 免费 |

申请邮件要求：简明扼要、有礼貌（范文见 2026-08-27 精算方向同学的申请）。

## 升级判据

- 邮件发出 3 个工作日无回复 → 群内 @ 导师或秘书确认是否收到
- 课题方向拿不准先写邮件问，不要盲投长文档
