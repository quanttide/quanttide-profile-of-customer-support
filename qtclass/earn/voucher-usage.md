# 代金券怎么用、怎么挣

## 适用场景

客户收到代金券后询问使用方式；想知道如何获取更多代金券；想约一对一咨询但不清楚价格。

## 解答

**使用规则**

- 代金券用于一对一沟通（咨询/预约），按小时计价
- 群内沟通不消耗代金券——群内提问免费
- 一对一预约价格与支持者职级对应：

| 职级 | 价格 |
|---|---|
| L5 | 500 元/小时 |
| L4 | 300 元/小时 |
| L3 | 200 元/小时 |
| L1 | 100 元/小时 |

**挣券渠道**

- 课堂实训任务：100 代金券/个（class.quanttide.com/learn）
- 众包任务：基准 1000 元/个（crowd.quanttide.com）

## 升级判据

- 客户要求指定特定对接人之外的安排（如定制合同、批量采购）→ 转商务
- 涉及券的兑换纠纷、过期争议 → 转人工核实发放记录
