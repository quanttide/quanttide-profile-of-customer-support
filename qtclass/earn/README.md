# 怎么挣代金券

挣代金券的所有方式索引。代金券可消费的方向见 [../spend/](../spend/)。

## 挣券方式

| 条目 | 一句话 | 报酬 |
|---|---|---|
| [training-task-reward.md](training-task-reward.md) | 完成课堂实训任务 | 100 券/个 |
| [crowd-task-reward.md](crowd-task-reward.md) | 完成众包任务 | 基准 1000 元/任务 |
| [representative-duty.md](representative-duty.md) | 代表履职初审 | 100 券/次 |
| [topic-review-bonus.md](topic-review-bonus.md) | 课题通过初审 | 奖励 500 券/项 |

**原则**：每个挣券渠道对应一种被公司认可并计价的劳动。渠道清单会持续增长（参与课堂教学活动、支持活动等均为候选方向）。

新增方式后在此表登记。
