# 预约一对一咨询怎么收费

## 适用场景

想使用代金券预约一对一咨询；询问咨询价格；想知道某位支持者的预约费用。

## 解答

- 一对一咨询**按小时计价，价格与支持者职级对应**：

| 职级 | 价格 |
|---|---|
| 首席 | 500 元/小时 |
| 资深 | 400 元/小时 |
| 高级 | 300 元/小时 |
| 中级 | 200 元/小时 |
| 初级 | 100 元/小时 |

- 预约方式：群内联系对应支持者，或通过支持人员转介
- **群内提问免费**——能公开回答的问题不建议花券约一对一

咨询之外的消费：申请超限额购买见 [申请有次数限制吗](extra-application-quota.md)。

## 升级判据

- 指定特定对接人之外的安排（定制合同、批量采购）→ 转商务
- 券的兑换纠纷、过期争议 → 转人工核实发放记录
