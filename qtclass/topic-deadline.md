# 课题有 deadline 吗？错过会怎样

## 适用场景

参与实训考核的候选人担心课题提交时限；因课程、实习等原因暂时无法提交，想知道资格是否失效。

## 解答

**制度分情况**：

- 到 deadline 后仍未提交 → 默认视为不再参与（无法逐一区分参与意愿，统一按此处理）
- **活跃参与者有保留权利**：已参与课堂教学活动、有提交记录的同学，可随时在自己准备好时发起课题，不受 deadline 约束
- 通过首个教学任务后开通正式实训基地账号 = 长期学习权限，课题可以慢慢来

**长期免费学员通道**：向 class@quanttide.com 报名"我要成为长期免费学员"，享受与活跃学员同等的保留政策。

**进度参考**：负数职级进度条（-3 纯学员 / -2 可参与小贡献 / -1 可较独立参与 / 0 可入职），见 [rank-progress.md](rank-progress.md)。

## 升级判据

- 特殊情况（考试周、生病等）需要延期 → 群内或邮件说明，人工确认
- 对定档结果有异议 → 找导师复核
