# 提交课题/申请前检查文档访问权限

## 适用场景

通过飞书云文档、GitHub 仓库链接等方式提交课题申请或作业；评审方反馈"没有权限可以访问"。

## 解答

提交前先用**未参与编辑的账号**（或让同学帮忙）打开链接自查一遍：

1. 飞书云文档：链接分享范围设为"互联网上获得链接的人可阅读"（或明确添加评审人）
2. GitHub 仓库：确认仓库 public，或已邀请评审账号为 collaborator
3. 附带的项目文档、素材链接逐个检查，不要只查主文档

历史案例：2026-08-29 一位候选人的课题申请因权限问题首次评审失败，重新设置权限后通过——权限意识是协作第一课。
